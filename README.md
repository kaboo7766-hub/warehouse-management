# منصة المستقبل التعليمية — الإصدار 0.11

## التشغيل
1. `npm install`  2. انسخ `.env.example` إلى `.env` واملأ بيانات مشروع Firebase  3. `npm run dev`
4. فعّل Email/Password في Authentication، وانشر `firestore.rules` من لوحة Firebase.
5. **أول مدير:** سجّل حسابًا عاديًا ثم غيّر حقل `role` إلى `admin` يدويًا من Firestore Console (لا توجد مفاتيح إدارة في الواجهة).
6. للنشر: اربط المستودع بـ Vercel وأضف متغيرات `VITE_FIREBASE_*`.

## الحالة
منفّذ: الهوية RTL + الوضع الليلي، الصفحة الرئيسية (مبسطة)، تسجيل الدخول/الخروج، الأدوار، قواعد Firestore، الصفوف والمواد، الدروس بروابط خارجية (بدون Firebase Storage)، سجل العمليات (الكتابة)، **(0.2)** تتبع التقدم ونسب الإكمال لكل مادة و«أكمل من حيث توقفت» (يتتبع آخر درس مفتوح، لا نقطة توقف داخل الفيديو)، اختبارات اختيار من متعدد وصح/خطأ بتصحيح تلقائي وعرض الإجابات وحفظ النتائج وإعادة الاختبار.
**(0.3)** إدارة المستخدمين وتغيير الأدوار من لوحة المدير، ربط ولي الأمر بالطالب (بواسطة المدير فقط)، لوحة ولي الأمر: تقدم كل ابن ونتائج الاختبارات ونقاط القوة (70%+) والضعف (أقل من 50%).
**(0.4)** الواجبات (إنشاء من المعلم، تسليم نصي مع رابط خارجي اختياري، تصحيح بدرجة وملاحظة، متابعة ولي الأمر)، والإشعارات داخل التطبيق (واجب جديد، تصحيح الواجب، إعلانات عامة من المعلم/المدير).
**(0.5)** اختيار الطالب لصفه الدراسي وتصفية الدروس حسب الصف.
**(0.6)** الألعاب (الحروف العربية والإنجليزية بنطق صوتي، الحساب، الذاكرة) بأصوات تشجيع ونقاط وشارات؛ الشهادات: تصدر للطالب عند إكمال كل دروس مادة، برقم فريد، وتُطبع أو تُحفظ PDF من نافذة الطباعة في المتصفح.
**(0.8)** تسجيل المعلمين كطلبات: يختار «معلم» عند إنشاء الحساب فيظهر عند المدير بزر «اعتماد كمعلم»، وجولة تعريفية تفاعلية تظهر مرة واحدة عند أول دخول لكل دور (طالب ومعلم وولي أمر ومدير).
**(0.10)** الصفحة الرئيسية: بانر شخصيات كرتونية (رسوم SVG أصلية)، وأقسام المدرسين وآراء أولياء الأمور وتواصل معنا تُدار من لوحة المدير (محتوى الصفحة الرئيسية) وتظهر فقط عند وجود بيانات حقيقية، مع الأسئلة الشائعة.
**(0.11)** واجهة اللوحة بتصميم تطبيقي: شريط علوي، قائمة جانبية بالأيقونات حسب الدور، غلاف ملوّن بإحصائيات حقيقية من قاعدة البيانات، وأعمدة بطاقات (اختصارات، إشعارات، روابط التواصل).
غير مكتمل: لوحة الطالب الكاملة والتقدم، الاختبارات، الألعاب، الواجبات، التقارير الأسبوعية والشهرية لولي الأمر، الإشعارات، الشهادات والنقاط، الاشتراكات (مفتاح `subscriptionsEnabled=false` فقط)، حذف/تعطيل المستخدمين وتقارير الإدارة.
**لم يُشغَّل build ولم يُختبر** (بيئة الإنشاء بدون إنترنت).


**ملاحظات أمنية (0.2):** بيانات الاختبار بما فيها الإجابات الصحيحة مقروءة للطالب تقنيًا، وحد إعادة الاختبار يُطبَّق في الواجهة فقط. التحصين الكامل يحتاج Cloud Functions (خطة Blaze) لاحقًا.

**ملاحظات (0.4):** علامة «مقروء» للإشعارات محفوظة في متصفح الجهاز فقط. الواجبات عامة لكل الطلاب (لا يوجد ربط بالصف الدراسي للطالب بعد). إشعار ولي الأمر عام للجميع وليس موجهًا لولي أمر محدد.

**ملاحظات (0.6):** النقاط والشهادات تُصدر من الواجهة، والقواعد تقيّدها (زيادة حتى 50 نقطة لكل عملية، شهادة واحدة لكل مادة) لكنها لا تتحقق فعليًا من الإكمال، والحل الكامل Cloud Functions. نطق الحروف يعتمد على أصوات المتصفح وقد يختلف على بعض الأجهزة.

**ملاحظة (0.8):** إنشاء حسابات المعلمين مباشرة من المدير (بدون تسجيل المعلم) يحتاج Cloud Functions؛ لذلك الاعتماد يتم بعد تسجيل المعلم بنفسه.
